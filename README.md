# Práctica Calificada 1: Estadística Espacial - QGIS

Este repositorio contiene las evidencias para la Práctica Calificada 1 del curso de Estadística Espacial.

## Estructura del Repositorio

- **`evidencias/01_instalacion/`**: Contiene la captura de pantalla de la instalación de QGIS.
- **`evidencias/02_capa_vectorial/`**: Contiene la evidencia de carga de una capa vectorial (Shapefile/GeoJSON) en QGIS.
- **`evidencias/03_capa_raster/`**: Contiene la evidencia de carga de una capa raster (TIF/DEM) en QGIS.
- **`datos/`**: Carpeta opcional para guardar los archivos `.shp` o `.tif` que descargues para tus prácticas (se recomienda no subir archivos muy pesados a GitHub).
